Xbox Sales Dashboard

Excel VBA macro that builds a one-page sales dashboard from raw data with one click.

VBA macro for Microsoft Excel that generates a one-page sales dashboard with slicers, KPI cards and charts in dark mode.

  • Download the workbook→

Highlights

  • One macro run (Alt+F11, then F5) creates the dashboard in a new sheet.

  • Slicers for Plan, Renewal and Type filter all visuals together.

  • KPI cards use IFERROR(GETPIVOTDATA(...), 0), so empty filters show 0, not #REF!.
